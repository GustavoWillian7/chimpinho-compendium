# Licenças das fontes (pesquisado em 2026-11-11)

| Fonte | Situação | Uso web (`@font-face`) |
|---|---|---|
| Chinese Rocks (Typodermic) | Versão grátis tem licença **desktop** (impressão, logos, gráficos estáticos) | **Precisa de licença web paga** (~US$ 109,95 a família, via MyFonts/Fontspring; confirmar em typodermicfonts.com/license) |
| Hapna Slab Serif (Inhouse Type / The Northern Block) | Comercial. Fontspring e MyFonts divergem sobre o publisher; preços ~US$ 18–31 por estilo, ~US$ 108 família de 6 | **Termos web não confirmados.** Verificar na página de licença do revendedor antes de comprar |
| Effra (Dalton Maag) | Comercial, a partir de £30,50 por peso; também em assinatura FontPass | **Termos web não confirmados.** Contato: licensing@daltonmaag.com |

## Decisão (final)
Sem orçamento para licenças. O projeto usa **somente fontes livres (SIL OFL)**: Anton, Source Sans 3 e Roboto Slab, via `@fontsource`. Chinese Rocks, Hapna e Effra **não** são usadas nem distribuídas.
Se um dia houver licença web, basta trocar as variáveis `--font-*`; registrar aqui data e escopo.
